static async Task< IResult > RealtyHub.ApiService.Endpoints.ContractsTemplates.GetAllContractTemplatesEndpoint.HandlerAsync ( IContractTemplateHandler handler)
static

Manipulador da rota que recebe a requisição para recuperar todos os modelos de contrato.

Este método chama o handler para buscar todos os modelos de contrato disponíveis e retorna o resultado.

Parâmetros
handlerInstância de IContractTemplateHandler responsável pelas operações relacionadas a modelos de contrato.
Retorna

Um objeto IResult representando a resposta HTTP:

- HTTP 200 OK com a lista de modelos de contrato, se a operação for bem-sucedida;

- HTTP 400 Bad Request, se houver erros na requisição.
