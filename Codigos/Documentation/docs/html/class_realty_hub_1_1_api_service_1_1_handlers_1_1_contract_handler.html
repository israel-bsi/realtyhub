Descrição detalhada

Responsável pelas operações relacionadas a contratos.

Esta classe implementa a interface IContractHandler e fornece métodos para criar, atualizar, deletar e buscar contratos no banco de dados.

Documentação dos Construtores & Destrutor

◆ ContractHandler()

Inicializa uma nova instância de ContractHandler.

Parâmetros
contextContexto do banco de dados para interação com contratos.

Este construtor é utilizado para injetar o contexto do banco de dados necessário para realizar operações CRUD nos contratos.

◆ DeleteAsync()

async Task< Response< Contract?> > RealtyHub.ApiService.Handlers.ContractHandler.DeleteAsync ( DeleteContractRequest request)

Realiza a exclusão lógica de um contrato, marcando-o como inativo.

Não remove o registro do banco, apenas altera seu status de ativo para inativo.

Parâmetros
requestRequisição que contém o ID do contrato a ser excluído.
Retorna
Retorna a resposta com o status da exclusão ou um erro se não for encontrado.

◆ GetAllAsync()

async Task< PagedResponse< List< Contract >?> > RealtyHub.ApiService.Handlers.ContractHandler.GetAllAsync ( GetAllContractsRequest request)

Retorna uma lista paginada de todos os contratos ativos, com opção de filtro por data.

Este método aplica paginação, filtra por data de emissão e retorna apenas contratos marcados como ativos.

Caso o filtro não seja fornecido, retorna todos os contratos ativos.

Parâmetros
requestRequisição que contém parâmetros de paginação e filtro.
Retorna
Retorna uma resposta paginada com os contratos ativos ou um erro em caso de falha.

Implementa RealtyHub.Core.Handlers.IContractHandler.
