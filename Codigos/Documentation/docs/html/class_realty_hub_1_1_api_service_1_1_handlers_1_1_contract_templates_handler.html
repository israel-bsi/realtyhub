Esta classe implementa a interface IContractTemplateHandler e fornece métodos para buscar modelos de contrato no banco de dados. ///

RealtyHub.ApiService.Handlers.ContractTemplatesHandler.ContractTemplatesHandler ( AppDbContext context)

Inicializa uma nova instância de ContractTemplatesHandler.

Este construtor é utilizado para injetar o contexto do banco de dados necessário para realizar operações CRUD nos modelos de contrato.

Parâmetros
contextContexto do banco de dados para interação com os modelos de contrato.
