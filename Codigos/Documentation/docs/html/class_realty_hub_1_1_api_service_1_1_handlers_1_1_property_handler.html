Descrição detalhada

Responsável pelas operações relacionadas a imóveis.

Esta classe implementa a interface IPropertyHandler e fornece métodos para criar, atualizar, deletar e buscar imóveis no banco de dados.

Documentação dos Construtores & Destrutor

◆ PropertyHandler()

RealtyHub.ApiService.Handlers.PropertyHandler.PropertyHandler ( AppDbContext context)

Inicializa uma nova instância de PropertyHandler.

Este construtor é utilizado para injetar o contexto do banco de dados necessário para realizar operações CRUD nos imóveis.

Parâmetros
contextContexto do banco de dados para interação com imóveis.
