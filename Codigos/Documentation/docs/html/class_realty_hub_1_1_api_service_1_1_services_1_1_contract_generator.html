Descrição detalhada

Classe responsável por gerar contratos utilizando templates e mapeamentos de variáveis.

A classe ContractGenerator utiliza um template em formato DOCX para substituir as variáveis de contrato e gerar um documento final em PDF.

void RealtyHub.ApiService.Services.ContractGenerator.GenerateContract ( Contract contract,
ContractTemplate? model )

Gera um contrato a partir de um objeto Contract e de um template opcional ContractTemplate.

Este método realiza as seguintes etapas:

1. Carrega o template DOCX do contrato.

2. Substitui as variáveis no documento conforme os mapeamentos gerados a partir do objeto Contract.

3. Salva o documento modificado como DOCX.

4. Converte o arquivo DOCX para PDF utilizando a biblioteca GrapeCity.

5. Exclui o arquivo DOCX temporário.

Parâmetros
contractObjeto Contract contendo os dados do contrato a ser gerado.
modelObjeto opcional do tipo ContractTemplate que define o template do contrato.
