Descrição detalhada

Classe responsável pelo envio de e-mails utilizando o protocolo SMTP.

A classe EmailService implementa a interface IEmailService e fornece métodos para enviar e-mails

◆ SendConfirmationLinkAsync()

Task< Response< bool > > RealtyHub.ApiService.Services.EmailService.SendConfirmationLinkAsync ( ConfirmEmailMessage message)

Envia um link de confirmação para o e-mail do usuário.

Este método configura um cliente SMTP e envia um e-mail formatado em HTML contendo um link para confirmação de e-mail.

Parâmetros
messageO objeto do tipo ConfirmEmailMessage que contém o e-mail de destino e o link de confirmação.
Retorna
Um objeto Response<TData> indicando o resultado do envio do e-mail.
