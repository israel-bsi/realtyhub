Descrição detalhada

Classe responsável por mapear as variáveis de contrato para substituição em modelos.

A classe VariablesContractMappings gera um dicionário de campos que serão utilizados para substituir as variáveis em um modelo de contrato.

Ela concatena campos padrão, de pessoa jurídica e pessoa física, além dos dados dos pagamentos.

RealtyHub.ApiService.Services.VariablesContractMappings.VariablesContractMappings ( Contract contract)

Inicializa uma nova instância de VariablesContractMappings com o contrato especificado.

O construtor recebe um objeto do tipo Contract e inicializa os dicionários de campos padrão, de pessoa jurídica e de pessoa física, mapeando os dados pertinentes do contrato.

Dictionary< string, string > RealtyHub.ApiService.Services.VariablesContractMappings.GetFields ( )

Retorna um dicionário com todas as variáveis mapeadas para o contrato.

Este método concatena o dicionário de campos padrão, os campos de pessoa jurídica, os campos de pessoa física e os textos referentes aos pagamentos, retornando um dicionário que mapeia cada variável ao seu valor correspondente.

Retorna
Um objeto Dictionary<TKey, TValue> contendo as chaves e os respectivos valores para substituição.
