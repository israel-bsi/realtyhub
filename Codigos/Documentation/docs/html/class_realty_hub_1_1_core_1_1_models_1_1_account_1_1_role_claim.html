Descrição detalhada

Representa uma declaração (claim) associada a uma role no ASP.NET Core Identity.

Cada instância desta classe corresponde a um registro na tabela AspNetRoleClaims e reflete a estrutura de um System.Security.Claims.Claim usada para autorização.
