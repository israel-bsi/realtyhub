◆ OnValidSubmitAsync()

async Task RealtyHub.Web.Components.Contracts.ContractFormComponent.OnValidSubmitAsync ( )

Manipula o envio válido do formulário, realizando a criação ou atualização do contrato.

Este método verifica se o formulário está em modo de emissão ou edição, chama o handler apropriado para criar ou atualizar o contrato, exibe mensagens de sucesso ou erro via Snackbar, dispara o evento de submissão e, em caso de sucesso, abre o diálogo para envio do contrato por e-mail.
