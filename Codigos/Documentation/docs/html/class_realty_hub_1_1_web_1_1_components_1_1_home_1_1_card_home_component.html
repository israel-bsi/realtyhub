Documentação das funções

◆ GetSrcPhoto()

string RealtyHub.Web.Components.Home.CardHomeComponent.GetSrcPhoto ( )

Obtém a URL da foto principal (thumbnail) do imóvel, ou a primeira foto disponível.

Busca a foto marcada como thumbnail em Property.PropertyPhotos. Se não houver, retorna a primeira foto. Monta a URL completa para exibição da imagem no card.

Retorna
URL da foto do imóvel.

◆ OnSendOfferClickedAsync()

async Task RealtyHub.Web.Components.Home.CardHomeComponent.OnSendOfferClickedAsync ( )

Abre o diálogo para envio de proposta para o imóvel exibido no card.

Exibe um modal utilizando OfferDialog, passando o ID do imóvel como parâmetro.
