override async Task RealtyHub.Web.Components.Home.PropertyDetailsPage.OnInitializedAsync ( )
protected

Inicializa o componente, buscando os detalhes do imóvel pelo ID informado.

Realiza a requisição ao handler para obter os dados do imóvel. Em caso de sucesso, preenche o modelo e atualiza a interface. Em caso de erro, exibe mensagem via Snackbar.
