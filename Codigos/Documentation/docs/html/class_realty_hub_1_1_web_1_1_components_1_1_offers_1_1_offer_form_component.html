Documentação das funções

◆ AddPayment()

void RealtyHub.Web.Components.Offers.OfferFormComponent.AddPayment ( )

Adiciona um novo pagamento à lista de pagamentos da proposta, limitado a 5 pagamentos.

Cada novo pagamento é criado com o tipo padrão EPaymentType.BankSlip.

◆ OnInitializedAsync()

override async Task RealtyHub.Web.Components.Offers.OfferFormComponent.OnInitializedAsync ( )
protected

Inicializa o componente, carregando os dados da proposta para edição ou preparando para envio de nova proposta.

Se OfferId for diferente de zero, busca os dados da proposta para edição. Caso contrário, busca os dados do imóvel e prepara o modelo para envio de nova proposta. Exibe mensagens de erro via Snackbar em caso de falha.

◆ OnValidSubmitAsync()

async Task RealtyHub.Web.Components.Offers.OfferFormComponent.OnValidSubmitAsync ( )

Manipula o envio válido do formulário, realizando a criação ou atualização da proposta.

Remove caracteres não numéricos do telefone do comprador, chama o handler para criar ou atualizar a proposta, exibe mensagens de sucesso ou erro via Snackbar, dispara o evento de submissão e redireciona para a listagem de imóveis em caso de sucesso.
