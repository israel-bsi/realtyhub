◆ OnValidSubmitAsync()

async Task RealtyHub.Web.Components.Properties.PropertyFormComponent.OnValidSubmitAsync ( )

Manipula o envio válido do formulário, realizando a criação ou atualização do imóvel e o gerenciamento das fotos.

Cria ou atualiza o imóvel via handler, gerencia o upload, atualização e remoção de fotos no servidor, exibe mensagens de sucesso ou erro via Snackbar e redireciona para a listagem de imóveis em caso de sucesso.
