◆ CreateAsync()

async Task< Response< Property?> > RealtyHub.Web.Handlers.PropertyHandler.CreateAsync ( Property request)

Cria um novo imóvel.

Envia uma requisição POST para a API com os dados do imóvel e retorna o resultado da operação. Caso a resposta não possa ser convertida, retorna um objeto de resposta com erro.

Implementa RealtyHub.Core.Handlers.IPropertyHandler.

◆ DeleteAsync()

async Task< Response< Property?> > RealtyHub.Web.Handlers.PropertyHandler.DeleteAsync ( DeletePropertyRequest request)

Exclui um imóvel pelo ID.

Envia uma requisição DELETE para a API utilizando o ID do imóvel a ser excluído e retorna o resultado da operação.

Implementa RealtyHub.Core.Handlers.IPropertyHandler.

◆ GetAllAsync()

async Task< PagedResponse< List< Property >?> > RealtyHub.Web.Handlers.PropertyHandler.GetAllAsync ( GetAllPropertiesRequest request)

Obtém uma lista paginada de imóveis.

Constrói a URL com parâmetros de paginação, filtro e termo de busca, e realiza uma requisição GET à API. Retorna um PagedResponse<List<Property>?> contendo os imóveis ou uma mensagem de erro em caso de falha.

Implementa RealtyHub.Core.Handlers.IPropertyHandler.

◆ GetAllViewingsAsync()

async Task< PagedResponse< List< Viewing >?> > RealtyHub.Web.Handlers.PropertyHandler.GetAllViewingsAsync ( GetAllViewingsByPropertyRequest request)

Obtém uma lista paginada de visitas associadas a um imóvel.

Constrói a URL com parâmetros de paginação, termo de busca, filtro e intervalo de datas, e realiza uma requisição GET à API para obter as visitas do imóvel especificado. Retorna um PagedResponse<List<Viewing>?> com as visitas ou uma mensagem de erro se a operação falhar.

Implementa RealtyHub.Core.Handlers.IPropertyHandler.

◆ GetByIdAsync()

async Task< Response< Property?> > RealtyHub.Web.Handlers.PropertyHandler.GetByIdAsync ( GetPropertyByIdRequest request)

Obtém os dados de um imóvel pelo ID.

Realiza uma requisição GET para a API com o ID do imóvel e retorna os detalhes do imóvel. Se a operação falhar, retorna uma resposta de erro.

Implementa RealtyHub.Core.Handlers.IPropertyHandler.

◆ UpdateAsync()

async Task< Response< Property?> > RealtyHub.Web.Handlers.PropertyHandler.UpdateAsync ( Property request)

Atualiza os dados de um imóvel existente.

Envia uma requisição PUT para a API com os dados atualizados do imóvel identificado por seu ID. Retorna o resultado da operação ou uma resposta de erro se a atualização falhar.

Implementa RealtyHub.Core.Handlers.IPropertyHandler.
