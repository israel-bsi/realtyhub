◆ CreateAsync()

async Task< Response< PropertyPhoto?> > RealtyHub.Web.Handlers.PropertyPhotosHandler.CreateAsync ( CreatePropertyPhotosRequest request)

Cria novas fotos para uma propriedade.

Valida se há arquivos para upload. Em seguida, cria um conteúdo multipart/form-data com os arquivos, incluindo cabeçalhos indicando se a foto é thumbnail e o seu identificador. Envia os dados para a API e retorna o resultado da operação.

Implementa RealtyHub.Core.Handlers.IPropertyPhotosHandler.

◆ DeleteAsync()

async Task< Response< PropertyPhoto?> > RealtyHub.Web.Handlers.PropertyPhotosHandler.DeleteAsync ( DeletePropertyPhotoRequest request)

Exclui uma foto de uma propriedade.

Envia uma requisição DELETE para a API utilizando o ID da propriedade e o ID da foto. Retorna uma resposta indicando sucesso ou falha na exclusão.

Implementa RealtyHub.Core.Handlers.IPropertyPhotosHandler.

◆ GetAllByPropertyAsync()

async Task< Response< List< PropertyPhoto >?> > RealtyHub.Web.Handlers.PropertyPhotosHandler.GetAllByPropertyAsync ( GetAllPropertyPhotosByPropertyRequest request)

Obtém todas as fotos associadas a uma propriedade.

Realiza uma requisição GET para a API utilizando o ID da propriedade e retorna a lista de fotos. Em caso de falha, retorna uma resposta de erro.

Implementa RealtyHub.Core.Handlers.IPropertyPhotosHandler.

◆ UpdateAsync()

async Task< Response< List< PropertyPhoto >?> > RealtyHub.Web.Handlers.PropertyPhotosHandler.UpdateAsync ( UpdatePropertyPhotosRequest request)

Atualiza as fotos de uma propriedade.

Envia uma requisição PUT para a API com as informações das fotos a serem atualizadas. Retorna a lista atualizada de fotos ou uma resposta de erro em caso de falha.
