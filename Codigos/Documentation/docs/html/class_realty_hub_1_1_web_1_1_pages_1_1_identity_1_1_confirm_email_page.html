override async Task RealtyHub.Web.Pages.Identity.ConfirmEmailPage.OnInitializedAsync ( )
protected

Inicializa o componente e confirma o e-mail do usuário.

Durante a inicialização, o componente define o estado de carregamento, envia uma solicitação de confirmação de e-mail utilizando as informações obtidas da query string, e atualiza o status e o indicador de sucesso com base na resposta do handler. Caso ocorra um erro, uma mensagem de erro é definida. Ao final, o estado de carregamento é desativado.
