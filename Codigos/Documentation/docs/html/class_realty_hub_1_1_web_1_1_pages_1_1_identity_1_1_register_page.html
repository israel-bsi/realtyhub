◆ OnValidSubmitAsync()

async Task RealtyHub.Web.Pages.Identity.RegisterPage.OnValidSubmitAsync ( )

Manipula o envio válido do formulário de registro.

Define o estado de carregamento, envia os dados para o handler de registro e, em caso de sucesso, exibe uma mensagem e redireciona o usuário para a página de login. Caso contrário, exibe uma mensagem de erro.
